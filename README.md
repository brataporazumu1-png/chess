# Chess Coach 7.0 — тренировка шахмат на iPhone

Сайт для GitHub Pages. Интерфейс на русском. Без сервера, без аккаунта, без платных API-ключей.

## Что входит

- Шахматная доска с встроенными векторными фигурами (не требует отдельной папки `pieces`).
- 42 пошаговых урока: во время урока пользователь делает **только свои ходы**. Ходы учебного соперника выполняются автоматически. Есть уроки за белых и чёрных, подсказки и сохранение прогресса.
- Шахматные задачи, часы с несколькими контролями, локальная игра против простого бота или второго игрока на одном устройстве.
- Загрузка открытых партий с Chess.com по нику (по умолчанию `margix_01`) и импорт `.pgn`.
- Разбор **каждого распознанного хода** на доске, оценка, предложение лучшего хода, основной вариант, возможность вернуться к ошибке и сыграть более сильный ход самостоятельно.
- Опциональный Stockfish 19 Lite single-threaded, который запускается в браузере при наличии интернета и доступности CDN.

## Установка на GitHub Pages

1. Распакуйте архив.
2. Загрузите **четыре файла непосредственно в корень репозитория** (не папку `ChessCoach-7.0`):
   - `index.html`
   - `lesson-coach.js`
   - `review-v7.js`
   - `stockfish-bridge.js`
3. В GitHub откройте **Settings → Pages** и выберите **Deploy from a branch → main → /(root)**.
4. URL репозитория `brataporazumu1-png/chess`: `https://brataporazumu1-png.github.io/chess/`.
5. Если Safari показывает старую версию, откройте страницу с `?v=7` или очистите данные старого сайта. В этой версии старые service workers удаляются при загрузке.

## Важно об анализе

На iPhone приложение **пытается** загрузить `stockfish-19-lite-single.js` и `.wasm` из официального npm-пакета `stockfish@19.0.1` через jsDelivr. При успешном UCI-подключении статус явно пишет `Stockfish`.

Если файлы недоступны (например, CDN заблокирован, сеть отсутствует или Safari не может создать движок), запускается **упрощённый, неглубокий учебный алгоритм**. Статус будет `Учебный разбор`, а оценки могут быть неточными. Это не официальная точность Chess.com и не GPT-комментарии.

Чтобы не зависеть от CDN, можно дополнительно самостоятельно добавить в папку `stockfish` рядом с `index.html` файлы:
- `stockfish-19-lite-single.js`
- `stockfish-19-lite-single.wasm`

Они доступны в пакете [`stockfish@19.0.1`](https://www.npmjs.com/package/stockfish), лицензия движка **GPL-3.0**. В этом архиве бинарников Stockfish **нет** — из сборочной среды их нельзя было надёжно получить.

Приложение анализирует стандартные партии с обычной начальной позиции. Нестандартные шахматные варианты и PGN с `[SetUp "1"]` / `[FEN ...]` могут не поддерживаться.

## Как пользоваться анализом

1. Откройте раздел **Разбор**.
2. Нажмите **Загрузить последние партии** или импортируйте `.pgn`.
3. Выберите партию и дождитесь, когда статус сменится с `Запуск Stockfish` на `Stockfish · разбор готов` или `Учебный разбор · готов`.
4. Нажимайте на ходы. Чтобы увидеть предложенный ход, выберите **Показать альтернативу**.
5. Выберите неточный ход и нажмите **Попробовать лучше**. Нужно самостоятельно сыграть лучший ход указанной стороной.

## Тесты

Проверены в автоматизированном Chromium с мобильным экраном: отображение 32 фигур без битых ссылок, урок за белых и чёрных с автоматическими ответами соперника, просмотр PGN, переходы по ходам, отсутствие критичных ошибок JavaScript и горизонтального переполнения. Отдельно смоделировано UCI-подключение к движку (это **не** запуск реального Stockfish). Физический iPhone не тестировался.
