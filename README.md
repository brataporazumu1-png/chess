# Chess Coach 5.0 — GitHub Pages / iPhone

30 проверенных легальных уроков, 6 задач, тренировочный бот, 11 контролей времени, просмотр публичных партий Chess.com аккаунта margix_01 и **учебные комментарии к каждому распознанному ходу**.

## Публикация
Загрузите **содержимое** этой папки в корень публичного GitHub-репозитория `chess` (файл `index.html` должен быть в корне). Settings → Pages → Deploy from a branch → main → /(root). Подождите обновления. Откройте адрес GitHub Pages в Safari и выберите «Поделиться» → «На экран Домой».

## Разбор партий
Откройте «Партии», нажмите «Загрузить партии за 3 месяца», затем нажмите на строку партии. Или импортируйте PGN. Просматривайте ходы стрелками или нажимая на список ходов. PGN должен начинаться со стандартной начальной позиции; варианты с FEN и некоторые нестандартные PGN пока не поддерживаются.

**Важно:** комментарии автоматически составляются по шахматным признакам (взятие, шах, рокировка, активность, незащищённая фигура). Это **не** оценка Stockfish, не классификация точности и не полноценный GPT-бот. Для глубокого анализа каждого хода требуется интеграция Stockfish WASM либо серверного движка. Данные Chess.com загружаются из публичного API при наличии доступа к сети. Никакой платный API не используется.
