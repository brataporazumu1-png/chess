# Chess Coach 2.0 — iPhone / GitHub Pages

Персональная бесплатная PWA для блица 3+2. Включает 3 интерактивных урока, свободную игру с проверкой легальности ходов, часы 3+2, загрузку публичных партий Chess.com пользователя `margix_01` за последние 3 месяца и импорт PGN для статистики результатов. **Stockfish, автоматический разбор ошибок и игра против компьютера пока не реализованы.** Часы работают только в свободной игре и не восстанавливают время при отмене хода; при отмене лучше сбросить часы.

## Публикация с iPhone

1. Скачайте ZIP и распакуйте в приложении «Файлы».
2. В Safari откройте https://github.com/new, создайте **публичный** репозиторий `chess-coach`.
3. В репозитории выберите **Add file → Upload files**. Загрузите **файлы из папки**, а не ZIP и не папку целиком: `index.html`, `chess.js`, `coach.js`, `manifest.webmanifest`, `sw.js`, `icon.png`, `icon-512.png`. Подтвердите **Commit changes**. Если кнопки нет, запросите настольную версию сайта Safari.
4. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, `main`, `/(root)`, **Save**.
5. Дождитесь публикации и откройте адрес вида `https://ВАШ_ЛОГИН.github.io/chess-coach/` в Safari. Выберите **Поделиться → На экран «Домой»**.

Данные партий запрашиваются из публичного API Chess.com непосредственно с устройства; при блокировке запроса можно импортировать PGN. Внешний интернет необходим для загрузки партий, но уроки доступны офлайн после установки. Результаты и прогресс уроков сохраняются на устройстве; загруженные партии пока не сохраняются после перезагрузки.
