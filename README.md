# Chess Coach 6 — приложение для GitHub Pages

Статический сайт на HTML/CSS/JS, без платного сервера и без Mac. Оптимизирован для iPhone Safari и «На экран Домой».

## Как обновить текущий сайт

1. Распакуйте ZIP. **Не загружайте сам ZIP в GitHub**: загрузите его содержимое.
2. В репозитории `brataporazumu1-png/chess` замените старые `index.html`, `style.css`, `app.js`, `review.js`, `engine.js`, `sw.js`, `manifest.webmanifest` и добавьте **новые** `content.js`, `analysis-worker.js`, а также папку `pieces` со всеми 12 SVG.
3. Все файлы (и сама папка `pieces`) должны быть в **корне** репозитория рядом с `index.html`.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/(root)` → Save.
5. URL после публикации: https://brataporazumu1-png.github.io/chess/
6. Если видна старая версия на iPhone, полностью закройте установленное приложение или откройте страницу в приватной вкладке Safari; service worker может кэшировать старый сайт. Также можно удалить старый ярлык с главного экрана и добавить заново.

## Что реально работает

- 42 интерактивных урока (30 прежних линий и 12 новых; белая/чёрная сторона). Ученик **ходит только за свою сторону**, соперник отвечает автоматически. Уроки — интерактивные пошаговые сценарии, а не адаптивный ИИ-наставник.
- Векторные фигуры собственной разработки, адаптивная мобильная доска, выбор фигуры нажатием, подсветка допустимых ходов, рокировка и превращение.
- Задачи на фиксированные позиции, локальное сохранение прогресса.
- Локальный учебный бот, 11 настроек часов, два игрока на одном устройстве, экспорт PGN.
- Загрузка публичных архивов Chess.com за три последних **игровых** месяца (обработаны возможные сетевые ошибки), фильтры и импорт PGN.
- Позиционный комментарий к каждому распознанному полуходу, просмотр вариантов, цветные предварительные пометки, подсветка найденной альтернативы и попытка исправить ошибку на доске.
- Позиционный алгоритм отдельно от интерфейса в Web Worker. Работает полностью в браузере. Без API-ключей.

## Ограничения, о которых важно знать

**В версии 6 НЕТ Stockfish.** В архиве нет библиотек стороннего движка. Двухполуходный поиск предназначен для обучения базовым принципам и поиска очевидных тактических провалов, но может давать ошибочные оценки. Его оценки **не совпадают** с метрикой «Точность» или официальным анализом Chess.com. Он не является генеративным языковым ИИ: русскоязычные комментарии формируются из реально сыгранного хода, конкретной позиции и локального поиска. Некоторые комментарии останутся простыми.

В этом варианте импорт PGN предназначен для обычных шахмат с начальной позиции. Chess960 и другие стартовые FEN не поддерживаются. Анализ ограничен первыми 180 полуходами. Интернет нужен только для загрузки Chess.com; локальные уроки, партии и анализ загруженного PGN работают без него после кэширования.

## Лицензии

Шахматные фигуры в `pieces/` нарисованы специально для Chess Coach 6 и не являются собственностью Chess.com. В проекте не используются логотипы или фигуры Chess.com. Воспользоваться данными Chess.com помогает публичный read-only PubAPI: https://support.chess.com/en/articles/9650547-what-is-the-pubapi-and-how-do-i-use-it
